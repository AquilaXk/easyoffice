# 포맷 지원 범위

포맷별로 읽기, 쓰기, 왕복 보존, 경고만 내는 항목, 거부 상한을 정리한 표입니다. 근거는 코드 파일 경로와 [policy-decisions.md](policy-decisions.md)의 PD 항목입니다. 코드나 PD에서 확인하지 못한 칸은 "미확인"으로 두었습니다. 마지막 대조는 2026-11-20(`acf29cd5`)입니다.

용어는 다음처럼 씁니다.

- **왕복 보존**: 열고 같은 형식으로 저장했을 때 값과 서식이 남는 항목.
- **경고만 내는 항목**: 저장·열기를 거부하지 않고 빠진 것의 종류와 개수를 상태줄과 응답 `warnings`로 알리는 항목.
- **거부 상한**: 넘으면 파일 전체를 거부하는 한도(Fail-Closed). 거부 오류는 `ResourceBudgetExceeded` 등으로 돌아옵니다.

## 8. 이 문서에서 미확인으로 남긴 것

- DOCX, ODT, ODP, RTF의 포맷별 개수·크기 상한은 공통 상한 외에 코드에서 확인하지 못했습니다.
- HWP 5.0 편집기의 항목별 왕복 보존 범위는 rhwp 엔진이 정하며 이 저장소에서 목록으로 확인하지 못했습니다.
- ODT와 ODP의 "경고만 내는 항목"은 PD에서 포맷별로 적힌 것을 찾지 못했습니다.
