## 변경 사항

- 관계형 데이터베이스 BASE와 무한 캔버스 BOARD를 더했습니다.
- 오른쪽 코파일럿 채팅 패널을 더했습니다. 사용자가 등록한 모델 서버에 연결합니다.
- 시트에 차트, 피벗 테이블, 그림, 셀 메모와 `FORECAST.ETS` 같은 함수를 더해 내장 함수가 313종이 됐습니다.
- 시트에서 수식을 입력하다 셀을 누르거나 끌면 참조가 들어가고, F4로 `$` 고정을 바꿉니다. 편집 칸이 글자 길이만큼 넓어지고, 범위 안 Enter·Tab 이동과 Ctrl+방향키 이동을 표 계산 프로그램 규칙에 맞췄습니다.
- 시트에 웹 표를 붙이면 병합과 서식이 따라오고, 행 높이를 끌어 바꾸거나 경계를 두 번 눌러 맞출 수 있습니다.
- 문서에 다른 오피스 프로그램의 글을 붙이면 글꼴과 그림이 남고, 한글 입력 중 실행 취소가 글자 단위로 끊기지 않습니다.
- 슬라이드를 좌표 기반 캔버스로 바꿨고, 문서에 다단계 목록, 다단, 각주, 변경 내용 추적을 더했습니다.
- 파일 처리 엔진의 압축·XML·PDF 쓰기 부품을 검증된 오픈소스로 교체해 결과 파일이 작아졌습니다.
- PDF 저장이 숨긴 레이어, 주석, 쪽 레이블, 첨부 파일을 유지합니다.
- 1904 날짜 체계 파일의 날짜가 1,462일 밀리던 문제와 다크 테마에서 선택 색이 보이지 않던 문제를 고쳤습니다.

## Changes

- Added BASE (relational database) and BOARD (infinite canvas).
- Added a copilot chat panel on the right. It connects to a model server you register.
- Sheets gained charts, pivot tables, pictures, cell notes, and functions such as `FORECAST.ETS`, for 313 built-in functions.
- In sheets, clicking or dragging cells while typing a formula inserts the reference, and F4 cycles the `$` anchors. The edit box grows with its text, and Enter/Tab inside a range and Ctrl+arrow moves follow spreadsheet rules.
- Pasting a web table into a sheet keeps merges and formatting. Row heights can be dragged or fitted by double-clicking the border.
- Text pasted into documents from other office apps keeps its fonts and pictures, and undo no longer splits Korean input mid-syllable.
- Slides now use a coordinate-based canvas. Documents gained multilevel lists, columns, footnotes, and tracked changes.
- Replaced the file engine's compression, XML, and PDF writing parts with proven open-source ones, so output files are smaller.
- PDF saving keeps hidden layers, annotations, page labels, and attachments.
- Fixed dates shifting by 1,462 days in 1904-date-system files, and selection color that was invisible in the dark theme.
