## 변경 사항

- 시트 서식 메뉴에 조건부 서식을 더했습니다. 셀 강조 규칙과 상위/하위 규칙은 값을 넣는 동안 시트에 미리 보이고, 데이터 막대·색조·아이콘 집합은 갤러리에서 바로 고릅니다.
- 규칙 지우기와 규칙 관리의 보기 범위(선택 영역·이 워크시트), 규칙별 서식 미리보기를 더했습니다.
- 조건부 서식에 테두리를 쓸 수 있습니다. "빨강 테두리"를 고를 수 있고 XLSX·ODS에 저장됩니다.
- 조건부 서식을 되돌린 뒤 다시 실행하면 칸이 칠해지지 않던 문제를 고쳤습니다.

## Changes

- Added conditional formatting to the sheet Format menu. Highlight and top/bottom rules preview on the sheet while you type a value, and data bars, color scales, and icon sets apply straight from a gallery.
- Added Clear Rules, a scope switch (selection or this worksheet) in Manage Rules, and a format preview for each rule.
- Conditional formats can now use borders. "Red border" is available, and borders are saved to XLSX and ODS.
- Fixed cells not being painted after undoing and then redoing a conditional formatting rule.
