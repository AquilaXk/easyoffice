# FORECAST.ETS 계열 클린룸 명세

`FORECAST.ETS`, `FORECAST.ETS.CONFINT`, `FORECAST.ETS.SEASONALITY`, `FORECAST.ETS.STAT`의 수식과 선택 사항을 공개 자료만으로 정한 기록이다. 구현은 `crates/easyoffice-sheet/src/functions_forecast_ets_cr.rs`, `functions_forecast_ets_opt.rs`, `functions_forecast_ets_args.rs`(Apache-2.0, PD-273)다. 이 문서는 구현보다 먼저 썼고, 구현의 모든 판단이 여기에 근거를 둔다.

## 0. 클린룸 조건

- 함수 문서(S1~S5), 공개 교과서(S6~S12), 논문(S13~S14)만 읽었다.
- 이 함수를 다른 소스 트리에서 옮긴 코드, 그 코드를 인용·요약한 글은 보지 않았다.
- 기준 앱 실측값은 월별 57점 한 계열(공식 예제 통합 문서에 저장된 계산값)뿐이다. 값이 필요한 판단은 5장 "선택한 방법"에 모았고, 실측 대조 결과는 9장에 있다.
- 출처 표기: `[S번호 장·절]`. 온라인 교과서는 쪽 번호가 없어 절 번호와 식 번호로 적는다. 종이책을 인용한 곳은 절만 적고 쪽은 확인하지 못했다고 밝힌다.

## 1. 인수와 오류 (함수 문서)

| 함수 | 인수 |
| --- | --- |
| `FORECAST.ETS` | `target_date, values, timeline, [seasonality], [data_completion], [aggregation]` [S1] |
| `FORECAST.ETS.CONFINT` | `target_date, values, timeline, [confidence_level], [seasonality], [data_completion], [aggregation]` [S2] |
| `FORECAST.ETS.SEASONALITY` | `values, timeline, [data_completion], [aggregation]` [S3] |
| `FORECAST.ETS.STAT` | `values, timeline, statistic_type, [seasonality], [data_completion], [aggregation]` [S4] |

문서가 정한 값과 오류 [S1~S4 "Syntax" 절의 인수 설명]:

- `target_date`: 날짜 또는 숫자. 기록 시간축의 끝보다 앞이면 `#NUM!`.
- `timeline`: 숫자 배열. 간격이 일정하고 0이 아니어야 한다. 정렬되어 있지 않아도 된다(함수가 안에서 정렬). 일정한 간격을 찾을 수 없으면 `#NUM!`. 중복 값이 있으면 `#VALUE!`. `values`와 크기가 다르면 `#N/A`.
- `seasonality`: 기본 1은 자동 탐지, 0은 계절성 없음("예측이 선형"), 양의 정수는 그 길이의 주기. 그 밖의 값은 `#NUM!`. 최대 8,760(1년의 시간 수), 넘으면 `#NUM!`.
- `data_completion`: 시간축에서 누락된 점이 30%까지 지원된다. 0은 누락을 0으로, 기본 1은 이웃한 점의 평균으로 채운다.
- `aggregation`: 같은 시각의 값을 합치는 방법. 기본 0은 AVERAGE, 나머지는 SUM, COUNT, COUNTA, MIN, MAX, MEDIAN이다. 문서는 숫자와 방법의 대응표를 싣지 않는다(5.8절).
- `confidence_level`: 0과 1 사이(양 끝 제외), 기본 95%. 범위 밖은 `#NUM!`. 문서는 "90% 신뢰 수준이면 미래 점의 90%가 예측에서 이 반경 안에 든다"고 설명한다. 함수는 이 반경(반폭)을 돌려준다.
- `statistic_type`: 1~8의 숫자. 문서는 번호표 없이 8개 통계를 이 순서로 나열한다: α, β, γ, MASE, SMAPE, MAE, RMSE, 감지된 간격. MAE 항목의 설명 문장은 SMAPE와 같다(문서 오기로 보고 MAE로 읽는다) [S4 "The following optional statistics can be returned"].
- 모형: `FORECAST.ETS`는 지수 평활의 "AAA 버전"이다 [S1 첫 문단]. 덧셈 오차, 덧셈 추세, 덧셈 계절 성분이다(ETS(A,A,A), 분류는 S8 8.5절).

## 2. 모형 수식

### 2.1 상태 공간 형태

관측 y_1..y_T, 계절 주기 m(2 이상). 아래 식에서 ε_t는 한 걸음 앞 예측 오차다. [S8 8.5절 ETS(A,A,A)]

```
y_t = l_{t-1} + b_{t-1} + s_{t-m} + ε_t
l_t = l_{t-1} + b_{t-1} + α ε_t
b_t = b_{t-1} + β ε_t
s_t = s_{t-m} + γ ε_t
```

계절성이 없으면(m이 0 또는 1) s 항을 뺀다. 이것이 ETS(A,A,N)(Holt 선형 추세)다 [S8 8.5절 ETS(A,A,N)].

### 2.2 평활 계수의 표기

상태 공간의 β와 γ는 Holt-Winters 성분 형태의 β*, γ*와 이렇게 이어진다: `β = α β*`, `γ = γ* (1 - α)` [S6 8.3절, S8 8.5절]. 성분 형태의 식은 [S6 8.3절]:

```
ŷ_{t+h|t} = l_t + h b_t + s_{t+h-m(k+1)}      k = floor((h-1)/m)
l_t = α (y_t - s_{t-m}) + (1-α)(l_{t-1} + b_{t-1})
b_t = β* (l_t - l_{t-1}) + (1-β*) b_{t-1}
s_t = γ (y_t - l_{t-1} - b_{t-1}) + (1-γ) s_{t-m}
```

두 형태는 같은 갱신을 낸다(ε_t = y_t - l_{t-1} - b_{t-1} - s_{t-m}을 넣으면 위 4식이 그대로 나온다). 구현은 오차 보정 형태로 돌리고, 사용자에게는 α, β, γ(상태 공간 형태)를 돌려준다(5.4절).

### 2.3 예측

h걸음 앞(h는 1 이상의 정수): `ŷ_{T+h} = l_T + h b_T + s_{T+h-m(k+1)}` [S6 8.3절 예측식]. 마지막 한 주기의 계절 값만 쓴다.

## 3. 초기값과 평활 계수 최적화

### 3.1 목적함수

덧셈 오차에서는 우도 최대화와 제곱오차합(SSE) 최소화가 같은 해를 준다 [S9 8.6절 "Estimating ETS models"]. SSE = Σ (y_t - ŷ_{t|t-1})² [S10 8.1절 식 8.2].

### 3.2 초기 상태 (선택한 방법, 5.2절)

초기 상태(l_0, b_0, s_{1-m..0})는 교과서에서 평활 계수와 함께 최적화하는 것이 원칙이다 [S9 8.6절]. 주기가 8,760까지 올라가 상태가 8,762개가 될 수 있어 같이 최적화하지 않고, 데이터에서 직접 계산하는 값으로 고정한다(5.2절).

### 3.3 평활 계수 (선택한 방법, 5.3절)

α, β*, γ*를 [0, 1]에서 찾는다. 전통적 제약 0<α, β*, γ*<1이 상태 공간 제약 0<β<α, 0<γ<1-α와 같다 [S9 8.6절 "Parameter constraints"]. 탐색은 6점 격자 → 상자 제약 Nelder-Mead 심플렉스 탐색 순서이고 도함수를 쓰지 않는다 [S14, S16]. 평가 횟수에 상한을 둔다(6장).

## 4. 계절성 자동 탐지

자기상관의 정의 `r_k = Σ_{t=k+1}^{T} (y_t-ȳ)(y_{t-k}-ȳ) / Σ (y_t-ȳ)²`, 계절 데이터는 계절 간격의 시차에서 자기상관이 크다, 백색잡음의 95% 경계는 ±1.96/√T다 [S11 2.8절, 2.9절]. 한 번 차분(`y'_t = y_t - y_{t-1}`)은 추세와 계절의 수준 변화를 줄인다 [S12 9.1절 "Differencing"]. 긴 계열에서는 Wiener-Khinchin 정리와 기수-2 고속 푸리에 변환(FFT)으로 같은 합을 `O(N log N)`에 구한다 [S17].

이 근거로 아래 방법을 골랐다(선택한 방법, 5.5절).

1. 격자로 완성한 계열(아래 7장 순서)에 한 번 차분을 하고 평균을 뺀다. 길이 N-1.
2. 시차 k = 1..K의 자기상관 r_k를 구한다. K = min(8,760, ⌊N/2⌋). `(N-1)×K > 4,096`이면 길이 `2^⌈log2(2(N-1))⌉` 기수-2 FFT 두 번으로 계산한다(직접 합과 오차 `1e-13` 이내).
3. 후보 시차는 `2 ≤ k ≤ K`, `r_k > 1.96/√(N-1)`, `r_k ≥ r_{k-1}`, `r_k > r_{k+1}`(r_{K+1}은 -∞)인 k다.
4. 후보가 없으면 계절성 없음(내부 주기 1). 있으면 가장 큰 r_k의 0.9배 이상인 후보 가운데 가장 작은 k가 주기다. 주기의 배수가 거의 같은 값을 갖기 때문에 가장 짧은 주기를 고른다.
5. 차분한 계열의 분산이 0이면(상수·선형 계열) 계절성 없음이다.

`FORECAST.ETS.SEASONALITY`는 탐지된 주기를 돌려주고, 계절성이 없으면 문서 규칙대로 `0`을 돌려준다 [S3] (5.5절).

## 5. 선택한 방법 (문서에 근거가 없는 부분)

함수 문서는 알고리즘 세부를 적지 않는다("AAA 버전", "30% 누락 지원" 같은 요약뿐). 아래는 이 구현이 정한 것이다.

1. **모형 계열**: 계절이 있으면 ETS(A,A,A), 없으면 ETS(A,A,N). 문서의 "계절성 0은 선형 예측"을 Holt 선형 추세(적합 가능한 α, β*)로 읽었다. 직선 회귀로 읽으면 STAT의 α, β를 정의할 수 없다.
2. **초기 상태**:
   - 계절 없음: 실측 3계열(9.5절)로 확인한 규칙이다. 첫 한 걸음 앞 오차가 0이 되도록 `l_0 = y_1 - b_0`로 두고, `b_0`는 전체 계열의 최소제곱 기울기다.
   - 계절 있음(N ≥ 2m): 앞 K = min(⌊N/m⌋, 4)개 계절의 블록 평균 μ_j를 블록 중심 시각 c_j = jm + (m+1)/2에 직선으로 맞춰 l_0(시각 0의 값), b_0(기울기)를 얻는다. s_i는 `y_{i+jm} - (l_0 + b_0 (i+jm))`의 j 평균이다. 마지막에 s의 평균을 빼고 그만큼 l_0에 더한다(합 0 정규화).
3. **평활 계수 최적화**: 모든 계수는 [0,1] 상자에서 찾는다. 1단계는 각 계수에 6개 값(0.02, 0.1, 0.25, 0.5, 0.75, 0.95)을 쓰는 격자다. 2단계는 격자 상위 3점에서 출발하는 상자 제약 Nelder-Mead 심플렉스 탐색이다(내부 반사 초기 꼭짓점 보폭 0.08, 좌표 허용 오차 `1e-6`, 상대 손실 허용 오차 `1e-10`, BSD-3-Clause 과학 계산 라이브러리 구조 차용 [S16]). 평가 횟수 상한은 1,500이다. 격자 첫 점에서 SSE가 0이면 즉시 종료한다.
4. **STAT의 α, β, γ**: 상태 공간 형태의 α, β = αβ*, γ = γ*(1-α)를 돌려준다(2.2절). 처음에는 성분 형태(β*, γ*)로 정했으나 기준 실측(9.5절, β = 0.499가 CONFINT 식의 상태 공간 β와 같음)으로 고쳤다. 계절성이 없으면 γ는 0이다(기준은 기계 엡실론).
5. **계절성 탐지 세부**: 4장의 차분 방식, 임계값, 0.9 규칙, 탐지 실패 시 주기 1은 모두 직접 정했다. 근거는 S11, S12의 일반 설명뿐이다.
6. **오차 분산 σ²**: `σ² = SSE / T`(T는 완성한 점 수). 교과서가 "잔차 분산"이라고만 적어(S7 8.7절) 최대우도 추정량을 골랐다.
7. **신뢰구간**: `FORECAST.ETS.CONFINT = z σ_h`, `z = Φ⁻¹((1+c)/2)`. σ_h는 S7 8.7절 표 8.7의 ETS(A,A,A) 식이다. m이 0 또는 1이면 γ=0, 계절 항(k 항)이 없는 ETS(A,A,N) 식이다. 상태 공간의 β = α β*, γ = γ*(1-α)를 대입한다.
   ```
   σ_h² = σ² [ 1 + (h-1){α² + αβh + β²h(2h-1)/6} + γ k {2α + γ + β m (k+1)} ],  k = floor((h-1)/m)
   ```
   `h ≤ 1`이면 σ_h = σ. h가 정수가 아니면 5.9절의 보간을 쓴다.
8. **집계 번호**: 문서는 이름만 나열하고 번호를 적지 않는다. 번호를 정한 근거는 이름의 알파벳 순서뿐이다.

   | 번호 | 방법 |
   | --- | --- |
   | 0, 1 | AVERAGE |
   | 2 | COUNT |
   | 3 | COUNTA |
   | 4 | MAX |
   | 5 | MEDIAN |
   | 6 | MIN |
   | 7 | SUM |

   0과 1을 둘 다 AVERAGE로 둔 것은 문서의 "기본 0은 AVERAGE"와 작업 지시의 "1~7"을 같이 만족시키는 선택이다. 숫자만 받는 수치 API에서 COUNT와 COUNTA는 같은 값(점 개수)이다. `aggregation`을 명시하면 한 번만 나온 시각도 같은 방법을 지난다(COUNT는 1). 8 이상, 음수, 정수가 아닌 값은 `#NUM!`.
   **중복 시각의 처리**: 순수 수치 API에서 `aggregation`이 `None`이면 중복 시각을 `#VALUE!`로 거부하고, 시트 수식 어댑터(`functions_forecast_ets_args.rs`)에서는 인수 생략 시 기본값 1(AVERAGE)을 넘겨 같은 시각의 값을 평균으로 합친다.
9. **비정수 h와 끝 시각(`target_date`)**: `h = (target - t_last) / step`이 정수가 아니면 ⌊h⌋와 ⌈h⌉의 예측(과 σ_h)을 선형 보간한다. `h = 0`(시계열 마지막 시각)에서 `FORECAST.ETS`는 완성된 계열의 마지막 관측값을 돌려주고, 미래 구간만 정의되는 `FORECAST.ETS.CONFINT`는 `#NUM!`을 돌려준다. 목표가 끝보다 앞서면 `#NUM!`(문서).
10. **간격 찾기와 달력 시간축**: 정렬한 시간축의 가장 작은 양의 차이를 간격으로 두고, 모든 차이가 그 간격의 정수배(오차 1e-6)인지 본다. 일수 간격이 일정하지 않은 달·분기·반기·연 단위 날짜 일련번호(같은 일자 또는 월말 기준일)는 시트 어댑터가 `year * 12 + (month - 1)` 연속 달 좌표로 변환해 넘긴다. 둘 다 맞지 않으면 `#NUM!`.
11. **누락 처리**: 간격의 정수배에 빈 칸이 있으면 누락이다. 누락 비율이 30%를 넘으면 격자 상한 검사보다 먼저 `#NUM!`으로 거부한다. `data_completion = 0`은 0으로, `1`은 이웃한 점 사이의 선형 보간(점 하나가 빠진 경우 이웃 평균)으로 채운다. 그 밖의 값은 `#NUM!`.
12. **최소 점 수**: 집계 뒤 3점 미만이면 `#NUM!`. 명시한 주기 m에서 N < 2m이면 `#NUM!`.
13. **MASE, SMAPE, MAE, RMSE**: 모두 학습 구간의 한 걸음 앞 오차 e_t = y_t - ŷ_{t|t-1}(t=1..N)로 계산한다.
    - MAE = mean|e_t|, RMSE = sqrt(mean e_t²) [S15 5.8절].
    - SMAPE = mean(2 |y_t - ŷ_t| / (|y_t| + |ŷ_t|)) [S15 5.8절 식에서 분모를 절댓값으로 바꿨다. 양수 데이터에서는 같다. 비율 단위(0~2)]. 분모가 0인 항은 0으로 센다. 비율 단위는 기준 앱 실측(세 번째 계열, 0.0171, 9.5절)으로 정했다.
    - MASE = mean|e_t| / (Σ_{t=m'+1}^{N}|y_t - y_{t-m'}| / (N-m')), 계절이 있으면 m' = m, 없으면 m' = 1 [S15 5.8절 "Scaled errors"]. 분모가 0이면 `#NUM!`.
    - 감지된 간격(8번)은 정렬한 시간축의 간격이다.
14. **`FORECAST.ETS.SEASONALITY` 반환**: 탐지된 주기를 돌려주고, 계절성이 탐지되지 않으면 `0`을 돌려준다 [S3].

## 6. 상한과 Fail-Closed

신뢰할 수 없는 입력(열자마자 계산되는 문서의 수식)에 대비해 아래를 넘으면 오류를 돌려주고 계산하지 않는다. 모든 루프와 버퍼 할당은 시트 엔진의 `EvalContext` 평가 단계·배열 메모리·마감 시간 예산을 충전한다.

| 항목 | 상한 | 넘으면 |
| --- | --- | --- |
| 입력 점 수·완성 격자 길이 | 32,768 | 시트 `#VALUE!` (순수 호출 `#NUM!`) |
| 계절 주기 | 8,760 [S1] | `#NUM!` |

실측값: `crates/easyoffice-sheet/tests/data/forecast_ets_excel_reference.json`(출처는 `THIRD_PARTY_NOTICES.md`). 월별 항공 승객 57점(2009-01~2013-09), 목표 24개(2013-10~2015-09), `FORECAST.ETS(…, 1, 1)`, `CONFINT(0.95, 1, 1)`, `SEASONALITY` 12, `STAT` α 0.251. 시험은 `functions_forecast_ets_cr_excel_tests.rs`다. 시간축은 달 번호 0..56으로 바꿔 넣었다(5.10).

기준 앱 `1e-6` 완전 일치 기준에는 못 미친다(전환 결정은 9.6절). 같은 입력의 이전 MPL 구현은 `FORECAST.ETS` 첫 점 3,868,499(+0.27%, +2.7e-3), 최대 2.5e-2, `CONFINT` 첫 점 -39%, 마지막 점 -11%, α 0.652로 역시 기준 앱과 맞지 않는다. 계열 1에서 `1e-12`로 일치하는 것은 주기와 `CONFINT(h)/CONFINT(1)`의 거리별 확장 비율뿐이며, 기준 계수 `(0.251, 0.001, 0.001)`을 교과서 순환식에 넣어도 예측값과 구간 절대 폭은 재현되지 않는다(9.2절 6번).

### 9.2 실측에서 읽은 기준 앱의 모형

실측 값만으로 확인한 사실이다.

1. **예측 구조**: 24개 예측은 `l + h b + s(h mod 12)`와 1e-9 이내로 일치한다. 12걸음 차이가 모두 같다(월 추세 b = 14,403.952). 덧셈 추세와 12개월 덧셈 계절이다.
2. **CONFINT 식**: `CONFINT(h)/CONFINT(1)`의 제곱 24개가 5.7절의 σ_h² 식에 상태 공간 계수 (α, β, γ) = (0.251, 0.001, 0.001)을 넣은 값과 1e-12 이내로 맞는다(h = 2의 비 1.063504에서 α + β = 0.252, h = 3에서 β = 0.001, h ≥ 13에서 γ = 0.001). 5.7절의 식은 맞다(시험 `the_reference_interval_follows_the_closed_form`).
3. **계수는 0.001 단위다**: α = 0.251, β = γ = 0.001(아래쪽 한계로 보인다). 클린룸의 탐색은 연속 값을 찾아 α = 0.659, β = γ = 0에 선다.
4. **σ²**: 기준 σ_1 = 82,843(σ² = 6.86e9). 클린룸의 SSE/T는 2.97e9(σ 54,497)다. 기준 α 0.251, β, γ로 최소제곱 초기 상태를 풀어도 SSE/T는 3.3e9다. 기준 σ² 는 이보다 약 2배 크다. 첫 계절 평균을 수준으로, 연간 차이에서 구한 기울기와 첫 계절 편차를 계절 값으로 둔 단순 초기값 두 가지(기울기 13,299와 16,345)로 같은 계수를 돌린 SSE/T는 6.7e9와 6.9e9로 기준 σ²와 같은 크기다. 기준 앱은 한 걸음 앞 SSE의 최적 초기값과 계수를 쓰지 않는 것으로 보인다(σ² = SSE/T 가정에서).
5. **최적화 목적**: 시험한 초기값(위 단순 초기값, 블록 평균 1·2·4개 계절을 쓴 변형, 최소제곱 기울기) 모두 한 걸음 앞 SSE 최소 α가 0.55~0.68이고 0.251이 아니다(β = γ = 0.001 고정). 기준 앱은 한 걸음 앞 SSE 말고 다른 목적(또는 다른 탐색)으로 계수를 정한다.
6. **재현 실패**: 계수 (0.251, 0.001, 0.001)의 오차 보정 순환식을 데이터에 거꾸로 돌려 기준 예측의 끝 상태에서 초기 상태를 구하면 초기 수준이 -9e11 같은 값이 나온다. 같은 계수에서 최소제곱 초기값의 끝 상태를 되돌리면 초기값이 4e-3 안에서 복원된다. 끝 상태를 이 순환식에서 얻을 수 있는 초기값이 없다. 계수를 HW 성분 형태(β* = 0.001 등)로 바꿔도 같다. 기준 앱의 순환식이 2.1절과 다르거나, 예측에 쓰는 계수가 CONFINT에 쓰는 계수와 다르다.

### 9.3 클린룸에서 맞추지 못한 이유

명세의 선택 항목 가운데 초기값(5.2), 최적화(5.3), σ²(5.6)가 원인 후보다. 공개 자료와 실측만으로는 위 6번의 불일치를 설명하는 순환식 또는 목적함수를 찾지 못했다. 맞추려면 계수 세 개를 실측 한 건에 맞춰 고르는 수밖에 없고, 그것은 다른 계열에 일반화되지 않는 과적합이다. 그래서 고치지 않았다.

### 9.4 두 번째 실측 계열과 좁혀진 범위

두 번째 계열: `crates/easyoffice-sheet/tests/data/forecast_ets_excel_reference_2.json`. 월별 24점(2024-01~2025-12), `FORECAST.ETS(…, 12)`(주기 명시, 나머지 기본값), 다음 12개월 예측값만 있다. 구간 폭, α는 없다.

| 항목 | 클린룸 | 이전 MPL |
| --- | --- | --- |
| 첫 점 (기준 437.134) | 437.076 (-0.013%, -1.3e-4) | 427.590 (-2.18%, -2.2e-2) |
| 12개 상대 오차 최대 / 평균 | 9.1e-2 / 4.0e-2 | 1.7e-1 / 1.2e-1 |

두 계열을 같이 `1e-6` 이내로 설명하는 기준 앱의 계절 순환식·초기화 규칙은 찾지 못했다(전환 결정은 9.6절). 계열 1의 값만으로 아래를 확인하고 배제했다(분석 스크립트는 리포 밖).

확인한 사실:

1. **끝 점에 고정된다(계열 1)**: 12걸음 뒤 예측이 `마지막 관측 + 12b`와 1e-9 이내로 같다(`FORECAST.ETS(…)` 12번째 = 3,954,015.4254 = 3,781,168 + 12 × 14,403.9521). 즉 끝 수준과 끝 계절 값의 합이 마지막 관측과 같다. 5.2절의 오차 보정 순환식은 α + γ = 1이거나 마지막 한 걸음 앞 오차가 0일 때만 이렇게 된다. 9.2절 2번이 읽은 CONFINT 계수(γ = 0.001)와 맞지 않는다. 시험 `the_reference_forecast_is_anchored_at_the_last_point`가 이 사실을 고정한다.
2. **추세는 전체 계열 회귀에 가깝다(계열 1)**: 기준 월 추세 14,403.95는, 기준 계절 값을 뺀 계열의 최소제곱 기울기 14,405.13과 8e-5 이내로 같다. 계절 더미를 함께 푼 최소제곱 기울기는 14,366이다. 첫 몇 해로 정한 초기 추세(13,299, 16,345)와 다르다.
3. **계절 값은 전체 계열 평균 편차에 가깝다(계열 1)**: 기준 계절 값은 이동평균 분해(-438k, -700k, …)나 더미 회귀의 값과 같은 모양이고 5% 안팎 작다(예: 1월 -401k 대 -425k, 2월 -671k 대 -696k).
4. **계열 2도 같은 모양이다**: 마지막 관측에 고정하고 추세 + 월 더미 최소제곱(기울기 8.056)으로 그린 예측이 기준 예측과 2.5% 안에서 비슷하다(예: 3번째 564.2 대 564.17, 12번째 606.7 대 605.8). 기준 12번째 예측에서 읽은 월 추세는 7.982이다.

배제한 규칙(둘 다 1e-6은 물론 1% 수준도 못 맞춘다):

- 5.2절 순환식에 계수 (0.251, 0.001, 0.001)을 넣고(성분 형태 변환 포함) 어떤 초기값에서 출발해도 계열 1의 끝 상태에 닿지 않는다(역방향 풀이가 -9e11 같은 초기 수준을 낸다).
- 계수 α = 1(수준 = 마지막 관측)에 최소제곱 초기값을 쓴 순환식(끝 추세 11,247, 최대 오차 2.6%).
- 최소제곱 초기값에 계수를 0.001 단위로 탐색(최적 α는 0.6~0.7 근처)하면 계열 1에서 α가 0.251이 되지 않는다.
- 전체 계열 더미 회귀를 초기값으로 쓰고 계수 세 개를 연속 값으로 자유롭게 맞춰도(Nelder-Mead) 두 계열의 상대 오차 제곱평균 제곱근이 0.66%(계열 1), 0.74%(계열 2) 아래로 내려가지 않는다.
- 첫 계절 평균 + 연간 차이 기울기, 블록 평균 직선, 최소제곱 기울기 등 단순 초기값(9.2절).

남은 후보는 순환식 밖에 있다. 기준 앱은 전체 계열의 회귀식(추세 + 월 더미)으로 추세와 계절을 잡고, 수준만 마지막 관측에 맞추는 구조일 가능성이 있다. 이 구조에서 σ²와 α = 0.251, β = γ = 0.001이 어떻게 나오는지는 설명하지 못했다. 이 가설을 가리려면 계절 없는 계열, 짧은 계열, 구간 폭이 함께 있는 계열 실측이 더 필요하다.

3. **σ²**: σ² = SSE/N이다. SSE는 첫 점을 뺀 12개 한 걸음 앞 오차의 제곱합이고, 나누는 수는 점 수 13이다(CONFINT와 SSE/13의 비 1.0000000000).
4. **SMAPE는 비율이다**: 기준 0.0171. 클린룸은 퍼센트를 돌려줘 고쳤다(5.13).
5. **계수 격자는 0.001 단위로 보인다**: 0.5, 0.499. 계열 1과 3의 계수가 모두 0.001의 배수다(0.251, 0.001, 0.001 / 0.5, 0.499).
6. **γ**: 계절 없는 계열의 γ가 기계 엡실론(2.22e-16)이다. 0이 아니라 `1 - (1 - 2.2e-16)` 꼴의 계산 잔여로 보인다(1에서 빼서 얻는 계수가 계절이 없을 때 1에 가깝게 나오는 구조로 추정). 구분할 수 없어 클린룸은 계절 없음에서 γ = 0을 돌려준다.

**맞지 않는 것**

- **계수 탐색 목적**: (0.5, 0.499)는 한 걸음 앞 SSE의 최소가 아니다. 초기값을 이 규칙으로 고정하면 최소는 α = 1.0, β = 0.435(SSE 80.78)이고 기준 계수의 SSE는 97.50이다. β = α - 0.001로 상한에 붙었고 α = 0.5는 이유를 모른다. 절대 오차, SMAPE, MAPE, 2·3·5걸음 앞 오차의 최소도 α = 0.5가 아니다. 세 계열의 계수는 모두 연속 최적값이 아니라 격자 위의 값이며 최적화가 수렴 전에 멈춘 것처럼 보인다.
- **STAT의 오차**: 기준 RMSE 2.9273, MAE 2.4830은 위 한 걸음 앞 오차(RMSE 2.8505, MAE 2.4372)와 다르다. 비가 일정하지 않아(1.027, 1.019) 단순한 분모 차이가 아니다. 초기 수준과 추세를 자유롭게 두고 RMSE, MAE, SMAPE를 한꺼번에 맞추려 했지만 일치하는 한 걸음 앞 오차 열을 찾지 못했다. 기준 MASE의 스케일은 MAE/MASE = 3.8194인데 한 걸음 차분 평균 절대값(5.3023)이나 어떤 단순한 변형과도 맞지 않는다. 클린룸 5.13의 정의(한 걸음 앞 오차, 한 걸음 차분 스케일)는 기준 값과 맞지 않는다.
- **계절 계열**: 위 초기 상태 규칙을 계열 1(계절 12)로 옮기면(전체 기울기, 더미 회귀 계절 값, 첫 한 걸음 오차 0) 예측이 2.8% 어긋난다. 계열 1의 끝 점 고정(9.4절 1번)이 이 규칙으로 나오지 않는다.

### 9.6 프로덕션 전환 결정 (PD-273)과 남은 과제

- QA 결정(2026-11-21, PD-273)으로 MPL-2.0 원본(`functions_forecast_ets.rs`, `tests/data/forecast_ets_vectors.txt`)을 삭제하고 이 클린룸 구현을 함수 등록부(`functions_forecast_ets_args.rs`)에 연결했다.
- 비계절 계열(계열 3)에서는 초기 상태(첫 값 수준 + 전체 계열 최소제곱 기울기), `σ² = SSE/N`, 순환식, 닫힌 식 `CONFINT`가 기준 앱 계수 `(0.5, 0.499)` 아래에서 예측값과 구간 폭 모두 `1e-9`로 재현됨을 확인해 반영했다(클린룸 자체 적합은 한 걸음 앞 SSE 최소해인 `α = 1.0, β = 0.4351`로 수렴하므로 첫 예측 `-0.85%`, 첫 `CONFINT` `-9.0%` 차이가 난다).
